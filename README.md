# 🎮 {TopDown2D}

Данная игра была создана по серии уроков TinyGames. Игра в 2D формате с пиксельной графикой. Проект был создан для обучения создания игр, а так же для практики рабоыт с GitHub



---

## 🚀 Быстрый старт

### Требования
* **Версия Unity:** `{6000.4.1f1}` (Использование другой версии может сломать сериализацию сцен).
* **Система контроля версий:** Требуется установленный **GitHub Desktop** 

### Как запустить проект локально:
1. Клонируйте репозиторий:
   ```bash
   git clone {https://github.com/istomanin/TopDown2D}.git
   ```
2. Откройте **Unity Hub**.
3. Нажмите кнопку **Add** -> **Add project from disk**.
4. Выберите папку с проектом и дождитесь окончания импорта ассетов (первый запуск может занять несколько минут).
5. Откройте стартовую сцену: `Assets/_Project/Scenes/SampleScene.unity`.

## 🛠 Технологический стек и Архитектура

* **Система ввода:** `{New Input System}`
* **Архитектура:** (например: *"Простейшая архитектура на ScriptableObjects, но по сути архитектуры нет"*).

### Структура папок (внутри Assets/)
Проект организован по следующему принципу:
* `_Project/` — весь кастомный код и контент нашей игры.
  * `Prefabs/` — готовые игровые префабы.
  * `Scripts/` — C# скрипты.
  * `Scenes/` — игровые сцены.
* `Plugins/` — сторонние плагины и SDK.
* `Settings/` — настройки графики (URP assets) и ввода.

## 🎮 Геймплей 



### Управление:
* `WASD` / `Стрелки` — Перемещение.
* `Space` — рывок.
* `ЛКМ` (Левая кнопка мыши) — Атака.

## 📦 Зависимости и сторонние ассеты

Проект использует следующие пакеты из Unity Package Manager (UPM) и сторонние ассеты:
* **NavMesh** — для работы системы навигации для NPC.
* **Cinemachine** — для плавной работы камеры.
